# AETHER · Лендинг частной авиакомпании

Одностраничный лендинг вымышленной частной авиакомпании **AETHER** —
на русском языке, тёмная премиальная эстетика. Собран на React + Vite +
Tailwind CSS.

## Что внутри

- **Hero с кроссфейдом видео** — три фоновых ролика, переключаются
  плавным затуханием (`opacity` + `transition-opacity`). Все ролики
  предзагружаются как blob для мгновенного переключения.
- **Живые часы** по московскому времени (`Intl.DateTimeFormat`, `Europe/Moscow`).
- **Переключатель фирменных маршрутов** — меняет активное видео и цвет
  акцента (розовый `#F598F2` / белый).
- **Пульсирующая точка** статуса посадки.
- **Reveal-анимации** (`revealUp` / `revealRight` / `revealLeft`),
  срабатывают один раз через `IntersectionObserver`.
- **Ховер-эффекты**: подчёркивание навигации, сдвиг ссылок, кнопка с
  заливкой снизу вверх.
- Секции: направления, каюты, призыв к бронированию, футер.
- Адаптив: брейкпоинты `mobile` (<810px) и `md-tablet` (810–1199px),
  мобильное меню на CSS Grid `grid-rows`.
- Доступность: семантические лендмарки, ARIA-подписи,
  `prefers-reduced-motion`.

Анимационная основа взята из набора готовых анимаций (motionsites.ai) и
переработана под тему авиакомпании.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # продакшн-сборка в dist/
npm run preview  # предпросмотр сборки
```

## Структура

```
src/
  App.jsx                  сборка секций
  data.js                  контент (маршруты, направления, каюты)
  hooks/useReveal.js       IntersectionObserver для reveal-анимаций
  components/
    Navbar.jsx             навигация + часы + мобильное меню
    Hero.jsx               главный экран
    VideoBackground.jsx    кроссфейд видео с предзагрузкой
    Marquee.jsx            бегущая строка преимуществ
    Destinations.jsx       список направлений
    Cabins.jsx             каюты
    BookCta.jsx            призыв к бронированию
    Footer.jsx             футер
  index.css                keyframes и утилиты анимаций
```
