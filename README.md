# AETHER · Лендинг частной авиакомпании

Одностраничный лендинг вымышленной частной авиакомпании **AETHER** —
на русском языке, тёмная премиальная эстетика. Собран на React + Vite +
Tailwind CSS.

## Что внутри

- **Hero — 2D-небо, вид с земли** (`SkyScene`, без видео): три сцены
  крос­сфейдом — северное сияние, ночной меридиан и закатный горизонт.
  В каждой сцене самолёт пролетает над головой (вид снизу, с бортовыми
  огнями и двойным инверсионным следом) по своей траектории — ↗ снизу-
  влево→вверх-вправо, → слева-направо, ↘ по нисходящей к горизонту. Плюс
  дрейфующие облака, звёзды, луна/солнце. Всё на SVG/CSS.
- **Флот** — галерея из двух реальных бортов (Bombardier Challenger 3500
  и Gulfstream G650ER): фото в карточках с подписью и описанием под
  снимком, характеристики, наведение с зумом фото и лайтбокс по клику.
  Изображения лежат в `public/jets/`.
- **Живые часы** по московскому времени (`Intl.DateTimeFormat`, `Europe/Moscow`).
- **Переключатель фирменных маршрутов** — меняет сцену и цвет акцента.
- **Пульсирующая точка** статуса посадки.
- **Reveal-анимации** (`revealUp` / `revealRight` / `revealLeft`) и
  пословный вывод текста, всё через `IntersectionObserver`.
- **Анимированные счётчики** показателей (count-up на скролле).
- **Карта маршрутов** — SVG с рисующимися пунктирными траекториями и
  самолётом, летящим по дуге (`animateMotion`), пульсирующий хаб.
- **Силуэт самолёта** во «Флоте» рисуется линией (`stroke-dashoffset`).
- **Посадочный талон** как CTA-карточка с перфорацией.
- **Ховер-эффекты**: подчёркивание навигации, сдвиг ссылок, кнопка с
  заливкой снизу вверх, свечение рамки карточек, свип строк направлений.
- **Полировка**: прогресс-бар скролла, навбар с блюром при скролле,
  зерно (film grain), плавный скролл, кастомный скроллбар, shimmer-заголовки.
- **Микровзаимодействия** (`Interactive.jsx`): параллакс в hero (небо и
  контент двигаются с разной скоростью), «магнитные» кнопки, 3D-наклон
  карточек с бликом, reveal-появления с блюром, marquee с затуханием краёв
  и паузой при наведении. Всё уважает `prefers-reduced-motion`.
- **Интро** (`Intro.jsx`) — лёгкая заставка при загрузке: логотип
  проявляется из блюра над заполняющейся линией, затем «шторка»
  поднимается и открывает сайт (клик — пропустить).
- Самолёт в hero — металлический градиент корпуса, свечение двигателей,
  сужающиеся инверсионные следы и лёгкое покачивание крыльями (крен).
- Секции: hero, бегущая строка, показатели, карта маршрутов, направления,
  каюты, флот, табло, приглашение, бронирование, FAQ, футер.
- **Живое табло** (`LiveBoard`) — счётчик бортов в воздухе, который
  меняется со временем, и табло рейсов с колонками вылет/прилёт: время
  прилёта и цены считаются автоматически по расстоянию, статусы
  (в пути / посадка / регистрация / задержка) обновляются со временем;
  клик по рейсу открывает бронирование.
- **FAQ** (`Faq`) — аккордеон частых вопросов на плавном `grid-rows`.

### Функциональность (демо, без бэкенда)

- **Поиск рейса** — виджет с реальными аэропортами (14 направлений):
  выбор откуда/куда, **в одну сторону или туда-обратно** (даты вылета и
  обратного рейса), число пассажиров. Время в пути и цены по классам
  считаются из реального расстояния (формула гаверсинуса), туда-обратно —
  оба плеча со скидкой на возврат; всё обновляется на лету.
- **Бронирование и оплата** — модальное окно: выбор тарифа
  (Эконом / Бизнес / Первый) → оформление → оплата картой (демо, без
  реального списания) → подтверждение «билет отправлен на почту».
- **Регистрация и вход** по почте и паролю. Личный кабинет с профилем и
  историей заказов. Клик по направлению открывает бронирование сразу.
- Данные (аккаунты, заказы, сессия) хранятся в `localStorage` браузера.
- Адаптив: брейкпоинты `mobile` (<810px) и `md-tablet` (810–1199px),
  мобильное меню на CSS Grid `grid-rows`.
- Доступность: семантические лендмарки, ARIA-подписи,
  `prefers-reduced-motion`.

Анимационная основа взята из набора готовых анимаций (motionsites.ai) и
переработана и расширена под тему авиакомпании.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # продакшн-сборка в dist/
npm run preview  # предпросмотр сборки
```

## Структура

```
src/
  App.jsx                  сборка секций
  data.js                  контент (маршруты, направления, каюты)
  hooks/useReveal.js       IntersectionObserver для reveal-анимаций
  components/
    Navbar.jsx             навигация + часы + мобильное меню
    Hero.jsx               главный экран
    VideoBackground.jsx    кроссфейд видео с предзагрузкой
    Marquee.jsx            бегущая строка преимуществ
    Destinations.jsx       список направлений
    Cabins.jsx             каюты
    BookCta.jsx            призыв к бронированию
    Footer.jsx             футер
  index.css                keyframes и утилиты анимаций
```
